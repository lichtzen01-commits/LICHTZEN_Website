# DESIGN.md library

Source: https://github.com/VoltAgent/awesome-design-md (MIT, see LICENSE). Each file in `references/` is a plain-markdown design system: YAML front-matter with tokens (colors, typography, radii, spacing, components) followed by prose rules.

## How to use

1. Pick the reference(s) that match the requested look from the index below. If the user names a brand, use `references/<brand>.md`; otherwise suggest 2–3 fitting options.
2. Read only the chosen file(s) — don't load the whole folder.
3. Apply its tokens and rules faithfully (CSS variables from `colors`, font stacks and scale from `typography`, radii/spacing/shadows, component patterns, do/don't rules).
4. To adopt one as the project's own design system, copy it to the project root as `DESIGN.md` and adapt names/colors to the LICHTZEN brand.
5. These are *inspired* interpretations: do not copy logos, trademarks, or proprietary fonts; use the listed fallback font stacks.
