# Front end system design resources

Source: https://github.com/greatfrontend/awesome-front-end-system-design (MIT, see LICENSE). The full curated list of links lives in `references/resources.md`.

## How to use

1. For a design task, structure the answer with the RADIO framework: **R**equirements (functional and non-functional), **A**rchitecture (components and responsibilities), **D**ata model (client state and its owners), **I**nterface (API between client and server and between components), **O**ptimizations (performance, network, UX, accessibility, i18n, security).
2. Find the matching section in `references/resources.md` (grep the heading) and read only that part.
3. Cite the most relevant case studies and guides as links. Fetch an article only when its details are needed; the list gives titles and URLs, not content.
