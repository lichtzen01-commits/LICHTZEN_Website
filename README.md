# LICHTZEN Website

리트젠 공식 홈페이지 데모와 향후 직원용 업무 시스템을 위한 저장소입니다.

## 구성

- 공개 홈페이지 데모: 회사·제품·적용 분야·기술자료·문의 화면
- 향후 업무 시스템 범위: 거래처·견적·PO·출하·PI/CIPL·입금·미수금
- 공개 정적 화면과 인증이 필요한 내부 업무 시스템을 분리합니다.

## 현재 배포 상태

- `site/index.html` 데모를 Vercel 임시 URL로 배포했습니다. 임시 URL은 배포 후 60분 동안 유효하며, Vercel 계정에 클레임해야 계속 유지할 수 있습니다.
- GitHub Pages는 이 저장소의 현재 비공개 설정에서 플랜 업그레이드 또는 저장소 공개 전환이 필요하다고 표시됩니다. 저장소를 공개하지 않았고, Pages 배포도 활성화하지 않았습니다.
- 문의·견적 및 관리자 화면은 데모이며 데이터를 저장하거나 ERP/CRM에 전달하지 않습니다.

## 보안과 데이터

- 실제 고객 PO, 입금 증빙, 계좌정보, 비밀번호, 서버 비밀키를 배포 파일에 넣지 마세요.
- 현재 PDF/이미지 분석 기능은 사용자가 파일을 올릴 때 외부 CDN에서 PDF/OCR 코드를 불러옵니다. 코드 검증과 자체 호스팅 전까지 기밀 도면이나 고객 자료를 업로드하지 마세요.
- 공개 데모와 실제 거래·고객 데이터를 분리하고, 실제 데이터는 인증과 서버 권한이 적용된 비공개 저장소에서 관리해야 합니다.
