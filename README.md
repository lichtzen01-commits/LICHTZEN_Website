# LICHTZEN Website

리트젠 공식 홈페이지 및 직원용 업무 시스템 프로젝트입니다.

## 구성

- 공개 홈페이지: 회사·제품·적용 분야·기술자료·문의
- 직원용 업무: 거래처·견적·PO·출하·PI/CIPL·입금·미수금
- 공개 정적 화면은 GitHub Pages 배포 대상으로 준비합니다.
- 업무 데이터와 고객 문서는 인증 및 서버 권한이 적용된 비공개 저장소에서 관리합니다.

## 현재 상태

저장소를 초기화했습니다. 홈페이지 파일 업로드와 GitHub Pages 배포는 준비 중입니다.

실제 고객 PO, 입금 증빙, 계좌정보, 비밀번호 및 서버 비밀키를 이 저장소의 배포 파일에 포함하지 않습니다.
