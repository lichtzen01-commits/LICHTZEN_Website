# LICHTZEN Website

리트젠 공식 홈페이지 데모와 향후 직원용 업무 시스템을 위한 저장소입니다.

## 구성

- 공개 홈페이지 데모: 회사·제품·적용 분야·기술자료·문의 화면
- 향후 업무 시스템 범위: 거래처·견적·PO·출하·PI/CIPL·입금·미수금
- 공개 정적 화면과 인증이 필요한 내부 업무 시스템을 분리합니다.

## 현재 배포 상태

- 테스트 사이트: https://lichtzen01-commits.github.io/LICHTZEN_Website/
  - GitHub Pages가 `main` 브랜치 최상위 폴더를 그대로 배포합니다.
  - 공개 홈페이지 67페이지만 포함합니다. 영업 시스템·관리자 화면·업무 데이터는 넣지 않았습니다.
  - 모든 페이지에 검색 차단(noindex)이 설정된 테스트 사이트입니다. 문의폼은 실제로 전송되지 않습니다.
- 사이트 갱신 방법: 테스트 번들 HTML에서 `scripts/build_static_site.py`로 정적 사이트를 만들고, GitHub Pages 주소(`/LICHTZEN_Website`)에 맞게 링크를 바꿔 최상위 폴더에 넣습니다. 도메인 최상위에 올릴 때(`deploy/site`)는 경로 변환 없이 씁니다.
- `site/index.html`은 이전 단일 파일 데모입니다.

## 보안과 데이터

- 이 저장소는 공개 저장소입니다. 실제 고객 PO, 입금 증빙, 계좌정보, 비밀번호, 서버 비밀키를 넣지 마세요.
- 현재 PDF/이미지 분석 기능은 사용자가 파일을 올릴 때 외부 CDN에서 PDF/OCR 코드를 불러옵니다. 코드 검증과 자체 호스팅 전까지 기밀 도면이나 고객 자료를 업로드하지 마세요.
- 공개 데모와 실제 거래·고객 데이터를 분리하고, 실제 데이터는 인증과 서버 권한이 적용된 비공개 저장소에서 관리해야 합니다.
