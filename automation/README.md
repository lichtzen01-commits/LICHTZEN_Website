# 메일 자동화 (Automation 브랜치)

이 브랜치는 itl@lichtzen.com 메일 자동 처리 작업용입니다. 홈페이지 배포(main)와 분리합니다.
이 브랜치에 올려도 홈페이지는 배포되지 않습니다(배포는 main의 deploy/site 변경만).

## 구성 (계획)
```
고객 → itl@lichtzen.com (메일플러그)
          │ 전달 (원본 보관)
          ▼
     회사 Gmail ── Apps Script가 5분마다 실행 (구글 서버, PC 불필요, AI API 없음)
          │ ① 키워드로 분류: 견적 / 발주 / 샘플 / A·S / 기타
          │ ② 라벨 · 담당자 전달 · 처리 기록 시트 · 첨부를 드라이브 폴더에 저장
          │ ③ 발주는 ERP 엑셀 업로드 양식으로 정리 (담당자가 확인 후 ERP에 업로드)
          └ ④ 분류별 템플릿 자동 답장 (이름만 바뀜, 한·영), itl@lichtzen.com 이름으로 발송
```

## 안전장치
- 자동응답·noreply·메일링 리스트·회사 주소에는 답장하지 않음
- 같은 사람에게 하루 1번만 자동 답장
- 처음 1주일은 시험 모드: 보내지 않고 "보냈을 내용"만 기록
- 분류 키워드와 답장 문구는 시트에서 수정 (코드 수정 불필요)
- 메일 비밀번호·키는 저장소에 넣지 않음 (Gmail 설정·스크립트 속성에만)

## 필요한 정보 (미정)
- 처리용 회사 Gmail 주소
- 분류 목록과 분류별 담당자
- 분류별 답장 문구 (없으면 초안 작성)
- ERP 이름·설치 형태·엑셀 업로드 양식
- 메일플러그 전달 설정, Gmail '다른 주소로 메일 보내기' 설정 (사용자)
