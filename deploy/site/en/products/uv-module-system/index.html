Applications

  • Optical films (prism sheets, reflective sheets, diffuser sheets, etc.)
  • Graphics (offset, gravure, OPV, screen, etc.)
  • UV curing of PDP surfaces and many other UV curing processes

Features

A high-efficiency modular UV curing system that fits many lines.

  • Easy to install, consisting of a compact UV irradiation unit (module) and power supply
  • Standardized modules for 1–40 kW lamps make application systems simple to build
  • Easy to configure even without UV curing experience
  • Modular construction reduces cost
  • Supports various signal interfaces for easy equipment connection
  • Shutter open/close control prevents heat damage
  • Construction optimized for roll-to-roll processes
  • Sliding lamp housing for easy replacement
