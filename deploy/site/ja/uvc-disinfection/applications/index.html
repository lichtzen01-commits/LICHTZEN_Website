UV-C消毒の適用空間

空間の使い方に応じて、254nm UV-Cと222nm Far-UVCから適切なソリューションをご提案します。

病院空間に合わせた2つの紫外線ソリューション

病室や集中治療室のように消毒中に空けられる空間は254nm UV-Cで迅速に消毒し、待合室や廊下のように人が居続ける空間は222nm Far-UVCで継続的な殺菌環境を作ります。

254nm / 222nm

介護施設

長期療養施設2か所で臨床評価を完了しました。病室は254nmで消毒し、共用スペースや食堂のように高齢者が過ごす場所は222nm Far-UVCで在室中も常時殺菌できます。

222nm

学校

教室のように一日中人がいる空間は、222nm Far-UVCで在室中も空気と表面を殺菌できます。空間の大きさに合わせてタイプA・B・Cから選びます。

222nm

オフィス

222nm

公共交通

バスや地下鉄のように狭く人の往来が絶えない空間には、コンパクトな222nmタイプA・Bモジュールが適しています。乗客がいる状態でも作動します。

222nm

トイレ

222nm

食品・飲料事業所

222nm

フィットネスセンター

運動器具を多くの利用者が共用するフィットネスセンターでも、222nm Far-UVCで運営を止めずに空気と表面を管理できます。

222nm

畜舎

家畜がいる畜舎でも222nm Far-UVCを継続運転でき、家畜伝染病の予防に活用できます。

222nm

カフェ・商業空間

営業時間中ずっと顧客と従業員がいるカフェや店舗には222nmタイプBが適しています。営業を止めずに殺菌環境を保てます。

254nm / 222nm

歯科・医療機関

診療中は222nm Far-UVCで診療室の空気と表面を殺菌し、診療のない時間は254nm Wonder-Ray®で空間全体を消毒する二重戦略をおすすめします。

よくある質問

病院ではどの製品を使えばよいですか？

病室、集中治療室、手術室、隔離室のように消毒中に空けられる空間には254nm Wonder-Ray®消毒器を、待合室・廊下・受付のように人が居続ける空間には222nm Far-UVCをおすすめします。

人が常にいるオフィスや学校でも使えますか？

はい。222nm Far-UVCは人がいる間も空気と表面を継続的に管理できるよう設計しています。空間の大きさに応じてタイプA・B・Cから選びます。

畜舎や食品工場にも適用できますか？

はい。家畜のいる畜舎や作業者が常駐する食品・飲料の製造・加工ラインでも、運営を止めずに222nm Far-UVCを使用できます。
