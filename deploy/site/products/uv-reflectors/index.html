● 집광형 (Elliptical Focus Type : Fig.1)

  • UV 광을 한 곳으로 집중시키는 형태로서 UV 경화기에 가장 많이 사용 (인쇄 경화용, 스크린 인쇄)

Fig. 1

● 평행광형 (Paralleled Type : Fig.2)

  • UV 광을 평행으로 반사시키는 형태로서 UV 소형 경화기 등에 적합 (반도체 본딩 및 접착)

Fig. 2

● 분산광형 (Diffuse Type : Fig.3)

  • UV 광을 확산시키는 반사갓 형태로서 손실이 많음.
  • UV 램프 발광량의 70%가 반사갓 쪽으로 방사되므로 반사갓을 선정할 때는 집광형 또는 평행광형을 사용하여 UV 효율을 높일 수 있다.

Fig. 3

제품의 적용 조건과 최종 사양은 상담 시 확인해 주세요.
