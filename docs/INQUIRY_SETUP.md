# 문의 메일 받기 설정 · 실시간 상담 검토

## 1. 지금 만들어진 것

- 오른쪽 아래 **문의하기 채팅**과 **문의 페이지(/contact/)** 둘 다 같은 발송 코드 `deploy/site/assets/inquiry.js`를 씁니다.
- **채팅 순서:** 분야 선택 → 내용 → 이메일 → 회사·성함(선택) → 요약 확인 + 개인정보 동의 → 제출.
- **메일 형태:** 제목은 `[홈페이지 문의] 분야 · 회사명`입니다. 본문 표에는 문의 경로, 분야, 내용, 회사, 이메일, 보낸 페이지, 화면 언어, 접수 시각(KST)이 들어갑니다. 메일에서 **답장**을 누르면 고객 이메일로 바로 회신됩니다.
- **스팸 대비:** 사람 눈에 보이지 않는 함정 칸(honeypot)을 넣어 두었습니다.
- **열쇠가 비어 있으면:** 테스트 모드로 동작합니다. 아무것도 보내지 않고 "테스트 사이트라 전송되지 않았습니다"라고 안내합니다.

## 2. 실제로 메일을 받으려면 (5분)

홈페이지가 GitHub Pages(서버 없는 정적 사이트)라서 메일 발송은 외부 서비스 **Web3Forms**에 맡깁니다.
- 무료 요금제는 월 250건입니다.
- 계정 없이 받는 메일 주소만 등록하면 됩니다.

1. https://web3forms.com 에 접속해 받을 주소(예: ltz@lichtzen.com)를 입력하고 **Create Access Key**를 누릅니다.
2. 그 메일함으로 열쇠(Access Key)가 옵니다. 이 열쇠는 페이지 코드에 공개되는 용도라 숨길 필요가 없습니다.
3. `deploy/site/assets/inquiry.js`의 `const ACCESS_KEY = '';` 따옴표 안에 열쇠를 넣고 main에 올립니다.
   - 열쇠를 채팅으로 알려주시면 제가 넣겠습니다.
4. 사이트에서 시험 문의를 한 번 보내 메일이 오는지 확인합니다. 처음 오는 메일은 스팸함도 확인하세요.

참고할 점

- **첨부 파일:** 무료 요금제에서는 파일을 보낼 수 없습니다. 지금은 파일 이름만 전달하고, 고객에게 "답장 메일로 보내 주세요"라고 안내합니다. 파일까지 받으려면 Web3Forms 유료 요금제나 다른 서비스가 필요합니다.
- **개인정보처리방침:** Web3Forms가 문의 내용을 거쳐 전달하므로 [공개 전 확정] **처리 위탁** 항목에 "Web3Forms(문의 메일 전달)"를 적어야 합니다. 국외 이전 여부도 함께 적습니다.
- **대안:** Formspree(무료 월 50건), Google Apps Script와 회사 Gmail 조합, 자체 서버 구축이 있습니다. 문의가 많아지거나 사내 CRM과 연결할 때 바꾸면 됩니다.

## 3. 실시간 상담 기능 검토

결론: **넣을 수 있습니다.** 다만 응답할 사람과 시간을 먼저 정해야 합니다. 응답이 늦은 실시간 상담은 메일 문의보다 인상이 나쁩니다.

| 방법 | 장점 | 단점 | 비용(대략) |
|---|---|---|---|
| **채널톡** | 국내 B2B에서 많이 씀. 웹 채팅·카카오톡·이메일을 한 화면에서 처리. 모바일 앱으로 응답. 업무 시간 밖에는 자동으로 메일 문의로 전환 | 버튼 디자인이 채널톡 기본형(색은 맞출 수 있음) | 무료 요금제 있음, 유료는 상담원 수에 따라 |
| **카카오톡 채널 1:1 채팅** | 국내 고객이 가장 익숙함. 지금 채팅 창에 "카카오톡으로 상담" 버튼만 추가하면 됨 | 해외 고객은 거의 쓰지 않음. 홈페이지 안이 아니라 카카오톡으로 이동 | 무료 |
| **tawk.to / Crisp** | 해외 고객용으로 무난. 다국어 | 국내 고객에게는 낯섦 | tawk.to 무료, Crisp 무료~유료 |
| **WhatsApp 비즈니스** | 해외 고객(동남아·중남미·인도)에게 익숙 | 국내 고객은 안 씀 | 무료 |

추천 순서

1. **지금:** 메일 접수(위 2번)를 먼저 켭니다.
2. **다음:** 지금 채팅 창에 **"카카오톡으로 바로 상담"** 버튼을 하나 추가합니다. 업무 시간에만 보이게 할 수 있습니다. 해외 화면에서는 WhatsApp 버튼을 보입니다.
3. **문의가 늘면:** 채널톡으로 옮겨 웹 채팅·카카오톡·메일을 한곳에서 처리합니다. 담당자 지정과 응답 시간 통계도 볼 수 있습니다.
4. **AI 답변:** 제품 자료로 1차 답변을 하고 사람에게 넘기는 방식입니다. 서버(또는 서버리스 함수)와 AI API 키가 필요합니다. 채팅 화면은 지금 것을 그대로 씁니다.

회사에서 정할 것: 응답 담당자, 상담 시간(예: 평일 09–18시), 카카오톡 채널 유무, 해외 문의 응대 언어.
