# 경쟁사 홈페이지 분석 (2026-11-19)

대상: IST METZ, GEW, 유버(UVER), 이와사키 전기(IWASAKI), EYEON. 각 사이트 메인 화면(PC·모바일)과 메뉴·제목·문의 버튼을 수집해 비교했다.
Excelitas는 봇 차단, Hönle는 접속 실패로 제외. 유버는 디자인 파일(CSS)이 다른 서버에 있어 화면 대신 메뉴·문구 구조로 분석했다.

## 2. 사이트별 장단점

**IST METZ**
- 장점: 제품·기술·적용·서비스·회사 5개 메뉴로 단순. 메인에 큰 숫자 3개로 규모를 보여줌. "수리 요청", "샘플 요청"처럼 고객이 실제로 하려는 일을 버튼으로 둠.
- 단점: 첫 화면을 쿠키 동의 창이 가림. 슬라이드라 첫 메시지가 흩어짐.

**GEW**
- 장점: 장비 영상으로 첫 화면에서 무엇을 하는 회사인지 바로 보임. "어떤 장비가 맞을지 모르겠다면?" 영역으로 고민 중인 고객을 상담으로 이끎. Service & Spares(부품·서비스)를 상위 메뉴로 둠. 25개 언어별 주소.
- 단점: 메뉴 하위 항목이 매우 많아 처음 온 고객에게 복잡함. 메인이 김.

**유버**
- 장점: 제품 메뉴 안에 **OEM/ODM(Customize)** 을 둠. 기술 메뉴를 생산시설·COB 집적화·광학·방열·조도 모니터링으로 나눠 기술력을 구체적으로 보여줌. Why UVER·인증/수상 페이지.
- 단점: 메인이 매우 길고(17,000px) 첫 화면까지 14초가 걸릴 만큼 무거움.

**이와사키 전기**
- 장점: **납품 사례(納入事例)** 를 상위 메뉴와 메인 첫 섹션에 둬 실적으로 신뢰를 줌. 카탈로그·도면·CAD 다운로드를 문의와 같은 곳에 묶음.
- 단점: 정보가 촘촘하고 공지 위주라 처음 온 해외 고객에게 무겁게 보임. 구조화 데이터 없음.

**EYEON**
- 장점: 메인이 짧고(4화면) 한 화면 한 메시지. 랩실·다운로드를 큰 버튼 두 개로, 마지막은 어두운 띠의 문의 영역으로 끝냄.
- 단점: 내용이 얇고 검색용 설명문이 없음.

## 3. 리트젠에 반영할 것

| 반영 | 출처 | 적용 위치 |
|---|---|---|
| 메인을 짧게, 한 화면 한 메시지 (6~7화면) | EYEON, GEW | 메인 (이번 수정) |
| "어떤 장비·램프가 맞을지 모르겠다면" 안내 → 고민 선택형 문의 | GEW | 메인 마지막 화면, 문의 페이지 (이번 수정) |
| 고객이 하려는 일을 버튼으로: 램프 교체·소량 제작, 샘플 테스트, A/S, 신규 장비 | IST, GEW | 문의 페이지 (이번 수정) |
| 큰 숫자로 규모 (수출·고객사·국가) | IST | 메인 글로벌 영역 (반영됨) |
| 장비 영상 첫 화면 | GEW | 메인 첫 화면 (반영됨) |
| 맞춤 제작·OEM 메뉴 | 유버 | 5단계 맞춤 제작·OEM 페이지 |
| 납품·적용 사례를 메인과 메뉴에 | 이와사키 | 5단계 적용 사례 (회사소개서의 장비 사례 11건 활용) |
| 기술을 세부 주제로 (광학 시뮬레이션·방열 설계·램프 제조) | 유버 | 5단계 기술 페이지 |
| 카탈로그 다운로드를 문의와 함께 | 이와사키, EYEON | 문의 페이지·자료실 |
| 언어별 주소(hreflang)로 다국어 | GEW, IST | 6단계 영문 페이지 |
| 피할 것: 첫 화면 가리는 팝업, 슬라이드, 너무 긴 메인, 무거운 페이지 | IST, 유버 | 전체 원칙 |
