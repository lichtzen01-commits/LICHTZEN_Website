특징

  • 부분적으로 높은 UV 강도가 요구되는 분야에 적합
  • 라이트가이드를 이용한 조사장치로 특정 조사부위의 UV 강도를 집중시켜 경화시간 단축
  • 두꺼운 접착제 / 점착제에 대해 신속 경화 가능
  • 마이크로프로세서 제어
  • PLC 인터페이스
  • 고연도 / 고역률
  • 컴팩트한 디자인
  • UV 램프 사용자 직접 ON/OFF 가능
  • 작업모드 기억 및 자동 복귀 기능
  • 발판스위치에 의한 셔터스위치 ON/OFF 기능
  • MANUAL / AUTO / PULSE MODE 지원
  • LCD 디스플레이
  • 램프 교체 용이
  • 경제적이고 합리적인 가격
  • CE 인증

적용

  • 칩 본딩, 광학부품 접착, 스크린 인쇄의 국부 경화
  • 전자부품 고정, 유리부품 접착 (세라믹, 렌즈 등)
  • 코일 권선의 마감처리(본딩), 액정의 접착 씰
  • 전기 재료 보호 코팅(Potting & Encapsulating) 접합
  • 열에 약한 재질의 접착, 의료기기 부품 접착
  • 기타 다양한 국부 경화를 필요로 하는 분야
